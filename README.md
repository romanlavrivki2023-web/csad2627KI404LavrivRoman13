## Варіант

## Опис проєкту

Цей репозиторій призначений для лабораторної роботи з AI-агента у VS Code Copilot,
який створює кросплатформний C++ проєкт Hello World із збіркою CMake,
юніт-тестами GoogleTest/CTest та перевіркою через GitHub Actions для Windows,
Linux і macOS.

## Запуск агента

1. Відкрити папку репозиторію у VS Code.
2. Відкрити Copilot Chat.
3. Вибрати агента `build-engineer`.
4. Виконати команду `/init`.

## Доступні commands

- `/git-init` — перевірити Git-репозиторій і налаштувати `.gitignore`.
- `/create-project` — створити C++ scaffold проєкту.
- `/create-build` — налаштувати CMake, GoogleTest/CTest і CI-скрипти.
- `/create-actions` — створити GitHub Actions workflow.
- `/check` — перевірити файли, збірку, тести та CI.
